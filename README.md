# PORSCHE HOUSE — Premium Online Showroom Demo

## Files
- `index.html`: Single-page storefront with inline HTML, CSS and JavaScript
- `img/`: Hero and vehicle photography assets used by the page

## Run locally
Open `index.html` in a modern browser. Keep the `img` folder beside it.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `README.md`, and the complete `img/` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Demo limitations
This is a portfolio/demo storefront, not an official Porsche website or an authorized retailer.
Login, membership points, favorites and the estimate cart use browser `localStorage`.
Consultation forms are demonstrational and do not transmit information.
No actual vehicle order, payment, financing, test-drive booking or dealer contact is performed.
